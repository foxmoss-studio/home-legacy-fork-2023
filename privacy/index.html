Privacy

Different things should have different policies.

This page covers the Foxmoss website itself. Apps have their own privacy policies because visiting a website and keeping a private life library in an app are not the same thing.

Website policy

The Foxmoss website

Last updated October 31, 2026

Foxmoss is a static website hosted with GitHub Pages. Foxmoss does not add advertising, developer analytics, account sign-in, or a tracking script to this site.

Hosting

Pages are delivered through GitHub Pages. When your browser requests the site, GitHub can receive ordinary web-request information such as your IP address, browser information, and the page being requested. GitHub's handling of that information is governed by its own privacy terms.

Fonts and stylesheets

The site currently loads the Alice font from Google Fonts and Normalize.css from cdnjs. Those services receive the browser requests needed to deliver those resources. Foxmoss does not use those requests as an analytics system.

Cookies and accounts

Foxmoss does not provide a website account or intentionally set its own analytics or advertising cookies on these pages. External hosting or resource providers may operate under their own technical and privacy practices.

Contact

If you email emira.support@gmail.com, Foxmoss receives the message and anything you choose to include so it can respond. That correspondence is separate from data stored inside Emira.
